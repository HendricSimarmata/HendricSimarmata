### 🤖 `whoami` (Tentang Saya)

Selamat datang di markas rahasia saya! Saya adalah seorang pengembang perangkat lunak yang 10% waktunya digunakan untuk menulis kode, dan 90% sisanya untuk mencari tahu kenapa kode tersebut tidak berjalan (padahal kemarin normal).

```javascript
const developer = {
  nama: "Hendric Simarmata",
  lokasi: "Indonesia 🇮🇩",
  keahlianUtama: ["Ctrl+C", "Ctrl+V", "Debugging sambil berdoa"],
  sedangBelajar: "Cara keluar dari editor Vim",
  mottoHidup: "Jika kodenya berhasil jalan, JANGAN DISENTUH LAGI!",
  faktaUnik: "Kode saya pernah jalan tanpa error pada percobaan pertama. Saya langsung curiga."
};
```

- 🔭 **Sedang sibuk:** Membuat program yang menyembuhkan *bug* lama dengan menciptakan *bug* baru yang lebih canggih.
- 🌱 **Sedang mendalami:** Teknologi masa depan, AI, dan cara menjelaskan ke klien bahwa fitur itu tidak bisa selesai dalam 5 menit.
- 🤔 **Butuh bantuan untuk:** Menemukan titik koma (`;`) yang hilang sejak tahun lalu.
- 💬 **Tanya saya tentang:** Pemrograman, teknologi, atau rekomendasi kopi saset terbaik untuk begadang.
